# SQL Marketing Campaign Analysis

This project contains SQL queries to analyze a marketing campaign dataset.

## Contents
- `marketing_campaign.sql` → all queries used in analysis
- `marketing_campaign.csv` → dataset 
- `screenshots/` → outputs of queries

## Tools
- MySQL Workbench
- Dataset: Marketing Campaign Data

## Queries Covered
- Basic SELECT, WHERE, ORDER BY, GROUP BY
- Subqueries
- Joins
- Aggregate functions (SUM, AVG, etc.)
- Views
- Index optimization
